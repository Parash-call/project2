## 🚀 Deployment to Render (render.com)

This project includes a ready-to-deploy `render.yaml` blueprint.

### 1-Click / Fast Deployment Steps:
1. **Push this project to GitHub**:
   ```bash
   git add .
   git commit -m "Bhai Dooj Surprise for Shikha Sapkota"
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```

2. **Deploy on Render**:
   - Go to [dashboard.render.com](https://dashboard.render.com/)
   - Click **"New +"** -> **"Static Site"**
   - Connect your GitHub repository
   - Fill in:
     - **Name**: `shikha-bhai-dooj` (or your choice)
     - **Build Command**: `npm install && npm run build`
     - **Publish Directory**: `dist`
   - Click **"Create Static Site"**!
   - Render will build and give you a live free URL (e.g. `https://shikha-bhai-dooj.onrender.com`) with free SSL.

## 🛠️ Tech Stack
- **React 18** with **Vite**
- **Tailwind CSS** with festive gradients and custom animations
- **HTML5 Canvas API** for the interactive golden scratch card
- **MediaRecorder API** for voice message recording
- **html-to-image** for high-resolution downloadable cards & certificates
- **Web Audio API** for synthesized festive ambient melodies and bell chimes (100% offline)
- **LocalStorage API** for saving quiz progress, coupons, and sister's reply note
